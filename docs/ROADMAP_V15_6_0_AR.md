# Daily Work Reports — خطة تطوير v15.6.0 (2026-11-18)

## نطاق العمل والأساس المؤكد
- مصدر Windows: `windows/DailyWorkReports_15.2.py` (Tkinter + SQLite + ReportLab).
- المصدر العام الحالي: 15.5.0، ومخرجات Windows EXE وAndroid Debug APK موجودة في `E:\ProTech\Releases`.
- حقل اختيار الموظف في Windows عند السطور ~8100 يستخدم `ttk.Combobox(state="readonly")` ويحتاج بحثًا فوريًا.
- تصدير PDF في `export_pdf_to_path` يُجزِّئ الصفوف إلى دفعات 6 أو 8، ويضع `KeepTogether` و`Spacer`، ما قد يخلّف فراغات كبيرة.
- تصدير الفترة الحالي عبر `combine_report_snapshots` ينتج ملخصًا مجمعًا؛ نحتاج وضعًا آخر يحافظ على الحدود بين التقارير اليومية.
- بيانات Windows السابقة v15.3: `%LOCALAPPDATA%\DailyWorkReports`؛ والبيانات العامة 15.5: `%LOCALAPPDATA%\DailyWorkReportsFlexible_v155`. كلاهما موجود على الجهاز وقت الفحص.
- Android القديم: `com.protech.dailyreports`؛ والجديد: `com.protech.dailyreports.flexible`، ولذلك لا يمكن اعتباره تحديث APK مباشرًا للإصدار القديم.
- عدم نقل بيانات المستخدم إلى GitHub أو الحزمة العامة أو ملفات الاختبار.

## تعريف النجاح
- لا يُحذف أو يُكتب فوق أي تقرير/إعداد/موظف موجود أثناء الترقية.
- اختيار الموظف عند كتابة جزء من اسمه وباللغة العربية أو الإنجليزية؛ تطابق مباشر وسريع دون اختيار خاطئ.
- تقرير بعد تقرير في PDF بخط فاصل واحد أو مساحة تعادل سطرًا واحدًا فقط؛ لا تُفرض صفحة جديدة إلا لضرورة الترحيل الطبيعي للمحتوى.
- خياران واضحان عند تصدير مدة: «تقارير متتابعة» (يحافظ على تقرير كل يوم) و«ملخص مجمع» (يعرض المجاميع).
- ترقية آمنة، قابلة للتحقق والاستعادة، واختبارات Windows 10/11؛ Android على محاكي/جهاز فعلي قبل Release.

## المرحلة الأولى — 40%: التوافق والبيانات والبحث الذكي
1. **نسخة أمان موثّقة**: نسخ `reports.db` و`config.json` و`company_assets` لكل مسار بيانات موجود إلى مجلد Backup مستقل بتاريخ/بصمة SHA256، وفحص `PRAGMA integrity_check`؛ عدم تغيير المصدر القديم.
2. **مدقق مخطط البيانات**: اكتشاف schema/config version مع اختبار قاعدة v15.3 و15.5 الحقيقية بقراءة فقط؛ بناء مخطط التحويل، وفحص جدول `reports` و`report_rows` و`users` و`templates` والحقول الديناميكية.
3. **معالج الترقية مرة واحدة**: شاشة تعرض (المصدر، الوجهة، عدد التقارير، احتمالات التعارض)، ثم `SQLite backup API` ومرحلة staging وتحويل transaction؛ استيراد بدمج آمن وعدم استبدال بيانات الوجهة الموجودة، ومراجعة التقرير/المستخدم المكرر بالمعرّف أو البصمة.
4. **Autocomplete للموظف على Windows**: تحويل `name_combo` إلى حقل قابل للكتابة مع نتائج مفلترة من `config["categories"][id]["people"]`؛ يبدأ البحث من أول حرف أو أي جزء، يدعم Up/Down/Enter/Escape، ويمنع حفظ اسم غير موجود إلا بإضافة صريحة.
5. **مطابقة نصوص عربية مناسبة**: إزالة التشكيل والتطويل وتوحيد الألف والياء لأغراض البحث فقط، دعم `casefold` للنص الإنجليزي، وإظهار الاسم المحفوظ كما هو دون تعديل؛ التحديث عند تغيير القسم أو إضافة/إعادة تسمية الموظف.

## المرحلة الثانية — 40%: الواجهة والتقارير والتصدير
6. **إعادة تنظيم واجهة العمل**: شريط علوي للمهام الرئيسية، حقل بحث الموظف واضح بجوار القسم، حقول عمل مرنة، وأزرار حفظ/تعديل/جديد/معاينة/تصدير/رجوع؛ شريط حالة يؤكد آخر حفظ.
7. **كثافة عرض أفضل**: هوامش ثابتة، إخفاء عناصر غير مستخدمة افتراضيًا، مقاسات Responsive لنافذة صغيرة، المحافظة على RTL، وعدم اقتطاع أزرار مع 125%-150% DPI.
8. **وضع تصدير التقارير المتتابعة**: حفظ عنوان/تاريخ/رقم كل تقرير مستقل داخل مستند واحد، وعرض التقارير متتابعة بالترتيب الزمني، مع مساحة سطر واحد بين نهاية تقرير وبداية التالي؛ الاحتفاظ بوضع «الملخص المجمع» القديم.
9. **محرك PDF متدفق**: إزالة تقسيم الصفوف الجامد إلى 6/8 واستبدال `KeepTogether` الذي يشمل جدولًا كاملًا بـ `LongTable` أو جدول قابل للتجزئة، و`repeatRows=1`، والحفاظ على عنوان التقرير مع أول صفّين؛ توزيع المحتوى حسب ارتفاع الصفحة الفعلي.
10. **تصميم التقارير**: عناوين بارزة، جدول متوازن RTL، سطور مضغوطة، إظهار الإجمالي في نهاية القسم، ترقيم الصفحات، خيارات A4 عمودي/أفقي، وضع ملون/أبيض وأسود، وعدم طباعة أقسام خالية افتراضيًا.
11. **معاينة قبل التصدير**: معاينة WYSIWYG مع خيارات «مضغوط / عادي» و«متتابع / مجمع» وتغيير الاتجاه والمقياس قبل حفظ PDF/طباعة.
12. **اتساق التصدير**: الحفاظ على جميع البيانات في Excel/CSV وعدم دمج سجلات الأيام بلا اختيار، واتساق أسماء الملفات وبيانات التعريف والتواريخ مع PDF؛ مراجعة الصور المصدرة وعدم إدخال فراغات مصطنعة.

## اختبارات القبول الإلزامية
1. اسم «عبدالرحمن محمد» يظهر بالبحث «رحمن» و«عبد»؛ ولا يختفي الاختيار بعد `Enter`.
2. تغيير القسم يغيّر قائمة المرشحين فورًا؛ ولا تدخل أسماء من قسم آخر عرضًا.
3. ترقية بيانات v15.3 مرتين لا تكرر التقارير، وتظل نسخة الأصل غير معدلة؛ كما لا تمس قاعدة v15.5 الموجودة مسبقًا.
4. عند اختيار 3 تقارير متتابعة يظهر كل عنوان وتاريخ، وبعد نهاية كل تقرير سطر واحد قبل عنوان التالي؛ لا صفحة فارغة.
5. جدول طويل ينتقل طبيعيًا للصفحة التالية مع تكرار رأس الجدول، دون منطقة فارغة كبيرة ناتجة عن `KeepTogether`.
6. طباعة/تصدير PDF A4 عربي في Windows 10/11، ولا يوجد نص مقطوع أو اتجاه معكوس.
7. فحص SQLite integrity قبل/بعد، ومقارنة عدد السجلات والتقارير والعناصر، واستعادة ناجحة من Backup تجريبي.
8. يمكن تثبيت Windows Setup أعلى النسخة المناسبة دون حذف بيانات المستخدم؛ توافق Android يثبت بمحاكي/جهاز ومفتاح توقيع معتمد.
